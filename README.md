# Hartford Wolf Pack Line Chart

Build game-night line charts for the Hartford Wolf Pack. Live at https://ethanmorren-hky.github.io/hwplinechart/

`index.html` is generated (roster, stats, schedule, fonts and logos built in) and refreshed each morning.

## NYR Ops Board

Rangers and Wolf Pack cap, roster and transaction simulator. Live at https://ethanmorren-hky.github.io/hwplinechart/nyr/

`nyr/index.html` and `nyr/data/` (league contracts from PuckPedia, rosters and stats from NHL.com) are generated and refreshed each morning.
